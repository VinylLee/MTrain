# 已弃用的 v3.4 试验归档

此分支保存一条基于 v3.3 修改的 v3.4 实验线。目标是降低增强训练数据的 hypothesis-only 捷径；阶段性诊断显示主要捷径指标下降，但数据质量信号不理想，因此暂时停止，不用于全量测试集生成或正式训练。

## 训练数据状态

- v3.3 基准：2,033 条原始数据、3,307 条增强数据，共 5,340 条。
- v3.4 实际生成：保留同一批 2,033 条原始数据，得到 2,290 条增强数据，目标为 3,307 条；生成器在计划请求耗尽后以部分完成状态停止。
- 当前 v3.4 只覆盖 5 种 MR，其中 synonym replacement 为 1,980 条。该 MR 配比与 v3.3 的 11 种 MR 不同。
- 本轮未生成四个全量测试集，提示词没有再修改，也没有筛选或重标生成数据。

使用 hypothesis-only TF-IDF + Logistic Regression。按原始来源分组做 80/20 划分；词表、IDF 和分类器只在 80% 拟合。特征不含 premise、MR 名称或 pair ID。

## 质量信号与限制

- 独立 DeBERTa / RoBERTa 对代表样本的标签一致率：v3.4 为 77% / 80%，v3.3 为 96% / 97.5%。这是模型代理指标，不是人工准确率。
- 结构审计发现 36 处冠词错误，常见形式为 “a individual”。
- INV 双向蕴涵代理在 v3.4 样本中较高，但 v3.3 与 v3.4 的可评分样本数不同，不能作为直接的总体质量比较。
- 130 条人工盲审包没有完成；因此没有人工质量非劣结论，也不满足质量冻结条件。
